NATIVE WINDOWS CAPTURE

Connect to Windows screenshots

Uses Windows’ built-in screenshot bar. Install a small local helper to let this extension open the bar and save your captures. The helper runs only while you’re taking a screenshot or using its settings.

Checking the screenshot connection…
  1. Click below to save the bundled installer to your browser’s Downloads location.
  2. Explorer opens with the installer selected. Double-click it and complete setup.
  3. Return here and check the connection. Then your toolbar button is ready.

Windows x64. No .NET required. Windows or your browser may ask you to confirm opening the unsigned installer. Installing this helper does not install Microsoft’s Snipping Tool app.

Click the browser toolbar icon next time. Select a capture in the Windows bar, or press Escape to cancel. You can close this tab; a capture already in progress continues.

Settings

The shortcut uses Win+Shift+S. If it does not open the bar on your PC, select compatibility mode.

Records launch timing, cancellation timing, capture decisions and errors locally. No clipboard text, screenshot pixels, or browsing history are included. Nothing is uploaded.

Needed on some Windows builds. This detection rule is provisional and may accept an unrelated copied image during a capture session. Turn it off to use recognized capture processes only.

Repair or remove the connection

To update or repair the helper, save and run the bundled installer again. To remove it, open Windows Settings → Apps → Installed apps → NativeSnip Windows Screenshot Connection. Remove the browser extension separately. Your screenshots remain saved.

No account. No cloud upload. Capture sessions end after one save, cancellation, or 90 seconds.
